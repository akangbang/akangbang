## Other Projects

### 🎯 Regression Analysis on YouTube Popularity (Mar 2025 — May 2025)

**Project Description**

Multiple linear regression model analyzing 40,000+ YouTube videos to predict view counts using engagement metrics and content metadata. Identified statistically significant interaction effects between likes and comments, demonstrating how combined audience behaviors amplify video popularity.

**Technical Stack**

R, multiple linear regression, Box-Cox transformation, statistical diagnostics

**Key Findings**

- Achieved adjusted R² of 0.81 with strong predictive stability
- Discovered significant likes × comments interaction effect (p < 2×10⁻¹⁶)
- Engagement metrics explained substantially more variance than metadata variables
- Model validated across training and testing sets for generalizability
